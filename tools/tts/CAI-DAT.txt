GIỌNG ĐỌC ĐÁP ÁN TIẾNG ANH (edge-tts) — tự cài, không phải làm gì

npm start lần đầu tự cài (chạy nền ~30 giây, log "[tts-en] cài xong edge-tts …"). Cài tay hoặc kiểm tra mạng: npm run setup-tts-en
(in kết quả đọc thử cả 8 giọng). Môi trường riêng: ~/.local/share/tiktok-live-games/tts-en-env, gói ghim ở requirements-en.txt.
Linux không có uv và báo thiếu venv: sudo apt install python3-venv (hoặc cài uv), rồi npm run setup-tts-en.

GIỌNG ĐỌC TIẾNG VIỆT (VieNeu-TTS) — cài một lần

Vì sao cần: OBS trên Linux không có giọng tiếng Việt nào, nên server game tự đọc bằng VieNeu-TTS (Apache-2.0, chạy ngay
trên máy bằng CPU, không cần mạng / tài khoản) — cùng bản 3.8.3 và 3 giọng (Ngọc Huyền, Trúc Ly, Hải Đăng)
mà tool aff (~/FileMySelf/Affiliate/affiliate-tool) đang dùng. Model (~500 MB) đã có sẵn trong ~/.cache/huggingface do
tool aff tải từ trước, nên không phải tải lại.

Cách cài nhanh: bash tools/tts/install-voice.sh  (in rõ từng bước, lỗi ở đâu báo ở đó)

Hoặc gõ tay (môi trường riêng, không đụng tool aff; chặn mọi bản phát hành mới hơn 20/10/2026):

  E=~/.local/share/tiktok-live-games/tts-env
  uv venv --python 3.12 "$E"
  uv pip install --python "$E/bin/python" --exclude-newer 2026-10-20 \
    "onnxruntime>=1.20" "sea-g2p>=0.9.1" "soxr>=0.3" "kaldi-native-fbank>=1.20" "tokenizers>=0.20" \
    "huggingface_hub>=0.20" "librosa>=0.11.0" "soundfile>=0.12" numpy
  uv pip install --python "$E/bin/python" --exclude-newer 2026-10-20 --no-deps "vieneu==3.8.3"

Server game đang chạy sẽ tự bật giọng đọc ở lần đọc kế tiếp (không cần khởi động lại); log in "[tts] giọng đọc VieNeu sẵn sàng" (nạp model ~10–20 giây, RAM ~1,3 GB).
Trang điều khiển → 5 · Màn hình: bật "🗣 Đọc cảm ơn quà / follow", chọn giọng, bấm "▶ Nghe thử giọng".
Muốn dùng Python khác: đặt biến môi trường TTS_PYTHON=/đường/dẫn/python trước khi chạy server.

An toàn: server giọng đọc chỉ nghe 127.0.0.1:3945; câu có từ tục tĩu / miệt thị / link / số điện thoại bị chặn ở cả màn
hình lẫn máy chủ (public/shared/profanity-filter.js); tên người xem có từ bẩn được đọc thành "bạn".
